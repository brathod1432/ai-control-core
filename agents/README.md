# Agents

Model-neutral agent and persona guidance.

Use this folder for role definitions, collaboration patterns, and multi-agent operating guidance that can work across AI assistants and agent runtimes.

Platform-specific agent setup notes belong under `integrations/platforms/`.

## Rules

- Keep core agent names functional.
- Avoid assuming one model, vendor, IDE, or chat client.
- Reference skills by normalized paths from `context/SKILLS_INDEX.md`.
- Preserve security boundaries from `security/SECURITY_POLICY.md`.
