# CV Design Palettes

Use color carefully. A CV should scan quickly, print cleanly, keep high contrast, and remain ATS-readable.

## Palette Rules

- Use one dominant neutral, one supporting neutral, and one accent.
- Keep accent usage below 10 percent of the page.
- Never place important text on low-contrast backgrounds.
- Use color for section rules, initials, icons, role labels, and small highlights.
- ATS-first DOCX variants must remain one-column and text-based. Use color only for name, section headings, or thin separator rules.

## Typography

Safe DOCX fonts:

- Aptos
- Calibri
- Arial
- Cambria
- Georgia
- Segoe UI

PPTX profile fonts:

- Aptos Display + Aptos
- Georgia + Aptos
- Segoe UI Semibold + Segoe UI
- Cambria + Calibri

ODT/LibreOffice-safe fonts:

- Liberation Sans
- Liberation Serif
- DejaVu Sans
- Noto Sans

## Layout Patterns

### ATS Classic

- One column
- Minimal color
- Conventional headings
- No essential text in shapes or images
- Best for online applications

### ATS Modern

- One column
- Name and section headings use a restrained accent color
- No sidebars, text boxes, skill bars, icons, or charts
- Skills remain plain text grouped with commas or short bullets
- Best for applications where a polished but parser-safe DOCX is needed

### Modern Sidebar

- Narrow sidebar for contact, skills, languages
- Wide body for summary and experience
- Use only when extraction remains readable
- Best for human-reviewed CVs

### Executive One-Pager

- Strong title block
- Profile summary
- Selected achievements
- Career highlights
- Board/advisory/leadership style

### Technical Portfolio

- Profile summary
- Skills matrix
- Selected projects
- Links to portfolio/GitHub
- Short experience bullets with technologies

### PPTX Career Snapshot

- Slide 1: identity, headline, value proposition
- Slide 2: career timeline
- Slide 3: signature projects or achievements
- Slide 4: skill map and tools
- Slide 5: target role fit or contact

## Graphical Elements

Use sparingly:

- Thin accent rules
- Small icons for contact methods
- Timeline dots
- Skill chips
- Project cards
- Achievement callouts
- Subtle section bands

For ATS submission copies, avoid these graphical elements entirely unless the same information also appears as normal body text.

Avoid:

- Decorative gradients behind body text
- Large low-value icons
- Skill bars without evidence
- Heavy backgrounds that do not print well
- Photos unless the target market expects them
