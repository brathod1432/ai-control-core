# Posting Guidelines

## Daily Posting Workflow

1. Pick one idea.
2. Edit the draft in Brijesh's voice.
3. Keep one idea per paragraph.
4. Add one engagement question.
5. Choose 8 to 12 hashtags.
6. Complete the confidentiality checklist.
7. Publish and reply to comments.

## Weekly Planning Workflow

Choose one theme, select Monday/Wednesday/Friday posts, prepare image prompts, create one carousel, create one poll, and prepare five thoughtful comments.

## Turn One Idea Into Formats

* Text post: Use the draft.
* Image post: Use the image prompt.
* Carousel post: Use the carousel template.
* Poll idea: Turn the engagement question into 3 or 4 options.
* Short video idea: Explain the problem, one example, one takeaway, and one question in 45 to 90 seconds.

## Best Structure

Hook, context, value, personal view, question.

## Readability Rules

Use simple English, short sentences, bullets where helpful, limited jargon, practical examples, and no hype.
