# Content Review Checklist

## Clarity

* [ ] Clear main point
* [ ] One main idea
* [ ] Strong hook

## Simple English

* [ ] Short sentences
* [ ] Limited jargon
* [ ] Easy to scan

## Professional Tone

* [ ] Respectful and calm
* [ ] Helpful, not promotional
* [ ] No exaggerated claims

## Confidentiality

* [ ] No internal company information
* [ ] No confidential product details
* [ ] No unreleased roadmap details
* [ ] No internal screenshots
* [ ] No customer/private data

## Usefulness

* [ ] Useful to network
* [ ] Practical insight
* [ ] Good for Brijesh's personal brand

## LinkedIn Structure

* [ ] Has a hook
* [ ] Has a question
* [ ] Has hashtags
* [ ] Short paragraphs

## Image Prompt

* [ ] Clear prompt
* [ ] 1080x1080 square
* [ ] No logos or confidential screenshots
* [ ] Text limited to 5 to 8 words
