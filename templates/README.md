# Templates

Reusable templates for skills, agents, and operational workflows.

Core templates should be model-neutral. If a template is specific to a client, model family, plugin system, or command syntax, place it under `integrations/platforms/`.

## Contents

- `skill-template/` - upstream-derived skill template generalized for internal use.
- `operational-templates/` - imported operational templates.

Review and adapt templates before publishing or enabling platform-specific behavior.
